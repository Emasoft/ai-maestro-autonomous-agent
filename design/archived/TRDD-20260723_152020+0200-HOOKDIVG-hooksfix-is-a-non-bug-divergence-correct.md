## The deferred question

Handoff carried a DEFERRED "hooksfix": `.claude-plugin/plugin.json`'s
`cpv.pipeline.intentional_divergence` lists `git-hooks/pre-push` (12-line, the file git
does NOT run), while the LIVE gate git runs is `.githooks/pre-push` (76-line
process-ancestry gate). Memory `publish-pipeline.md` [^7] framed this as a latent bug
("the entry names the DEAD one, so the live gate is undeclared"). It was deferred because
the correct target "depends on CPV force-template's hook-path handling, which is NOT
verified."

## The blocking fact, now VERIFIED

CPV's `standardize_plugin.py` manages the pre-push hook at **`git-hooks/pre-push`** — that
is its canonical path (`gen_pre_push_hook`, the template map, and the force-template list
all use `git-hooks/pre-push`). This repo overrides which hook git RUNS via
`core.hooksPath=.githooks`. So the two paths are on DIFFERENT axes:

- **CPV canon path** (what `intentional_divergence` / force-templates / drift-check act on)
  = `git-hooks/pre-push`.
- **git's live selector** (what actually gates a push) = `.githooks/pre-push` (via
  `core.hooksPath`), regenerated by publish.py every run.

## Decision — the declaration is CORRECT; no code change

- `intentional_divergence` naming `git-hooks/pre-push` is **right**: it names the path CPV
  manages, telling force-templates "don't regenerate this" and suppressing any canon-drift
  flag on CPV's own hook path.
- The live `.githooks/pre-push` correctly needs **no** entry — CPV never compares or
  force-templates a non-canon path, so there is nothing to declare.
- **Neither file is a deletable ghost:** `git-hooks/pre-push` is CPV's required canon
  artifact (deleting it would trip a "canon file missing" check and `standardize --fix`
  would regenerate it); `.githooks/pre-push` is the live gate.
- Proof: CPV v3.2.0 `--strict` passes clean and does NOT flag `git-hooks/pre-push`
  (only the 3 by-design RC-PIPELINE-DRIFT-001 warnings on ci/release/notify remain).

## What actually changed

Only the WRONG MEMORY. `publish-pipeline.md` [^7] was revised in place: its valuable core
("this repo has TWO pre-push hooks, `core.hooksPath` decides which git runs") is kept; its
conclusion ("live gate undeclared → latent bug") is corrected to the verified truth and
carries a greppable guardrail — **do NOT repoint the divergence to `.githooks/pre-push`**,
which would un-declare CPV's canon file. Root cause recorded: a category error conflating
CPV's canon-path axis with git's hooksPath-selector axis.
