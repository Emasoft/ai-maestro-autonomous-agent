**The load-bearing one is F1.** Claude Code fixed this exact class in its own isolation
three times in this range — 2.1.212 (`.claude/worktrees` symlink), 2.1.216 (`.claude`
symlink on workflow/scheduled-task writes), 2.1.217 (background-session cwd not
canonicalized, "which could let sessions escape their workspace folder") — plus 2.1.220
(`/rewind` refusing symlinks **and hard links**). This plugin's own check had the same
defect: `case "$TARGET" in $HOME/agents/$MY_AGENT_NAME/*)` matches the string the caller
typed, not the inode it lands on. The plugin exists to stop cross-agent writes; a scope
check that compares literal strings does not stop them.

## Change set

1. **`layers.md` §Programmatic path check** — canonicalize target AND roots before
   comparing; refuse a write through an existing file with link count > 1 (hard links
   have no second path for `realpath` to resolve, so canonicalization alone cannot see
   that escape). Add the Layer-3 catch-all row.
2. **`workspace-isolation/SKILL.md`** — step 2 becomes *canonicalize* (not merely
   "normalize"), the inline example uses the resolving form, and the checklist item
   matches.
3. **persona FORBIDDEN #1** — full redirect set (`git -C`, `--git-dir`, `--work-tree`,
   `GIT_DIR=`, `GIT_WORK_TREE=`) + "a path that RESOLVES there counts".
4. **persona WRITABLE SCOPE** — two clauses: mid-session directory additions do not
   widen scope; branch before starting work so a background preserve cannot land on a
   shared branch.
5. **persona Propagate to sub-agents + Sub-agent AMP ban** — make propagation
   transitive to nesting depth 3, and name the two spawn caps.
6. **README `## Running unattended`** — the caps that silently stall a long run, and the
   Bash-permission changes that now fail closed into a prompt.
